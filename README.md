## Project Description
This project is a menu-driven Student Record and Result Management System developed using the C programming language. It helps manage student information and academic results.

## Features
1. Add student records.
2. Display all student records.
3. Search students using SAP ID.
4. Delete student records.
5. Calculate CGPA using available semester SGPAs.
6. Calculate average CGPA by year.
7. Sort students by SAP ID.
8. Sort students by name.
9. AI Academic Advisor with academic recommendations.

## Technologies Used
- Programming Language: C
- Concepts: Structures, Arrays, Functions, Loops, Conditional Statements, and Sorting.
- AI Feature: Rule-based academic recommendation using if-else statements.

## How to Run
1. Open an online C compiler such as Programiz.
2. Copy the code from `590033218.c`.
3. Paste the code into the compiler.
4. Click Run and use the menu.

## AI Academic Advisor
The advisor checks a student's CGPA and provides a performance category and recommendation:
- 8.5 and above: Excellent
- 7.0 to 8.49: Good
- 5.0 to 6.99: Needs Improvement
- Below 5.0: Requires Immediate Attention
